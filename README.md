# TINY OS

**Графическая ОС, собранная с нуля, с рабочим интернет-браузером.**

Название проекта: **TINY OS** (в ISO записано как `TINY_OS`).

Настоящая загружаемая операционная система с нуля, а не веб-эмулятор.
Версия **gen0.5**. Образ диска занимает **67 072 байт**, работает в QEMU.
В репозитории также есть готовый загрузочный ISO.

## Что внутри

- **16-битный загрузчик** (`boot.S`, ровно 512 байт): читает ядро с диска,
  включает A20, включает VESA 1024×768 с линейным фреймбуфером и уходит
  в 32-битный защищённый режим.
- **32-битное ядро** (`kernel.c`):
  - **двойная буферизация**: сцена без курсора (0x200000), готовый кадр
    (0x600000), вывод в VESA-память;
  - при движении мыши перерисовываются **только два прямоугольника 12×16**
    под старым и новым курсором; наведение на кнопки тоже обновляет только
    кнопку — полная перерисовка экрана больше не происходит;
  - рабочий стол с «живым» пейзажем: звёздное небо, солнце с свечением
    и два слоя силуэтов гор, окрашенные в цвет текущей темы;
  - восемь окон со скруглёнными рамками, градиентными заголовками,
    пиксельными иконками приложений и **`объёмными` кнопками**
    **свернуть / развернуть / закрыть**;
  - **таблица дескрипторов прерываний (IDT)**: 256 записей, 32 вектора
    исключений CPU с отдельными обработчиками; при ошибке ядро показывает
    экран **KERNEL PANIC** с номером исключения, кодом ошибки и EIP и
    останавливает машину вместо самопроизвольной перезагрузки;
  - **PC speaker**: команда `beep` и звук паники через канал 2 таймера PIT;
  - **CPUID** определяет производителя процессора, **uptime** считает
    секунды с момента загрузки — всё видно в SYSTEM INFO;
  - окна перетаскиваются мышью за заголовок и **меняют размер** за правый
    нижний угол (у каждого окна свой минимальный размер);
  - **Alt+Tab** переключает окна, **Ctrl+W** закрывает активное; после
    закрытия или сворачивания фокус переходит к верхнему оставшемуся окну;
  - панель задач с активными кнопками и подсветкой текущего окна;
  - **меню «Пуск»** по кнопке **OS** или клавише **F8**: иконки пунктов, образец
    темы и подвал с версией;
  - **настоящая минимизация**: жёлтая кнопка сворачивает окно, повторный клик
    по его кнопке на панели задач — разворачивает; **двойной клик по заголовку**
    разворачивает/восстанавливает окно; клик по неактивному окну поднимает его;
  - **Notes** поддерживает несколько строк: **Enter** добавляет новую строку,
    Backspace удаляет символ; **Ctrl+S** сохраняет заметку на хост,
    **Ctrl+O** загружает её обратно (`tinyos_fs/notes.txt`);
  - **терминал (F9)** с виртуальной файловой системой и Linux-подобными
    командами: `pwd`, `ls`, `cd`, `mkdir`, `cat`, `git clone/status/log`,
    `apt`/`pkg`/`dnf` для системных пакетов, `pip` для Python,
    `which`, `uptime`, `uname`, `history`, `beep`, `calc`, `panic`,
    `ps`, `kill`, `resume`, `play`, `stop`, `top`, `snake`, `dmesg`, `free`,
    `df`, `du`, `tree`, `head`, `tail`, `wc`, `edit`;
    история команд — **↑/↓**;
  - **настоящие системные пакеты**: `apt install` скачивает RPM-пакеты
    через `dnf download --resolve` на хосте, распаковывает их в
    `tinyos_fs` и регистрирует файлы и зависимости в `apt_installed.json`;
    установленная программа запускается по имени в песочнице `bwrap`
    (объединённый `/usr`, без сети и без доступа к PID хоста);
  - **реальная установка Python-пакетов**: `pip install` запускает pip
    на хосте и кладёт файлы в `tinyos_fs/site-packages`; список пакетов —
    `installed_packages.json`;
  - **калькулятор (F10)**: мышь и клавиатура, операции `+ - * /`,
    Backspace, C, защита от переполнения;
  - **кооперативные задачи**: планировщик выполняет фоновые задачи
    (часы, звук, игра) по таймеру PIT; **TASK MANAGER (F11)** показывает
    список задач, состояния и счётчики, а `ps`/`kill`/`resume` управляют
    ими из терминала; это не процессы в смысле Linux;
  - **SNAKE (F12)**: игра со змейкой на стрелках, Space начинает игру,
    счёт и рекорд выводятся в окне;
  - **PC speaker**: три мелодии через команду `play 0|1|2` и `stop`;
  - **текстовый редактор**: `edit FILE` загружает файл, Ctrl+S сохраняет
    его обратно по тому же пути;
  - **журнал ядра**: `dmesg` показывает сообщения загрузки, IDT, PIT,
    CPU и события остановки задач;
  - **5 тем оформления** (F4 или пункт меню), живые дата и время из CMOS RTC;
  - PS/2 мышь с поддержкой **колеса прокрутки** и клавиатура.

## TINY BROWSER — интернет внутри QEMU

Одно из окон — браузер. У него есть **редактируемая адресная строка** с
кареткой (клик мышью задаёт позицию, работают ←/→, Home/End, Backspace/Delete,
Ctrl+L — новая строка, Ctrl+R — обновить), кнопки **BACK / FWD / GO / HOME**,
история переходов (F6/F7 или Ctrl+←/→),
кликабельные ссылки с подсветкой при наведении, прокрутка (стрелки,
PageUp/PageDown, колесо мыши), **полоса прокрутки** и счётчик строк в строке
состояния. Собственный компактный HTML-рендерер понимает заголовки, абзацы,
`<hr>`, маркированные и **нумерованные** списки, **`<pre>` с сохранением
переносов**, `<blockquote>`, `<code>`, `<img alt>`, `<b>`, сущности и `<title>`.
Заголовки выделены жирным с подчёркиванием, `<b>` тоже рисуется жирным.
Ссылки можно выбирать с клавиатуры: **Tab / Shift+Tab** переводят фокус,
**Enter** открывает выбранную ссылку, **Esc** снимает фокус.
Клавиатура различает регистр, поэтому в адресе можно писать строчные буквы,
а Shift+цифры/знаки дают `? & = + _ < > @ # % ( ) ! "`. `nethelper.py` перед
отдачей вырезает `<script>`, `<style>` и комментарии, чтобы страница быстрее
загружалась и больше текста помещалось в буфер.
Можно ввести просто домен (`example.com`) или поисковый запрос — он уйдёт
в Bing (RSS-режим); `nethelper.py` превращает ленту в компактную страницу
с кликабельными ссылками. Это работает из России, в отличие от DuckDuckGo.

Страницы загружаются **по-настоящему из интернета**. Поскольку в ядре нет
TCP/IP-стека, используется мост:

```
QEMU COM1  ──UNIX socket──>  nethelper.py (хост)  ──urllib──>  интернет
        <── u32 длина + HTML ──
```

Ядро само рисует полученный HTML. Помощник запускается автоматически
через `run.sh`.

> Ограничение: это не полноценный браузер — нет JavaScript, CSS и таблиц.
> Страницы отображаются текстом со ссылками. Но сеть реальная: любой URL,
> который открывается через `urllib`, откроется и здесь.

### Как пользоваться

1. Запустите `./run.sh` (он сам поднимет `nethelper.py`).
2. Нажмите **F5** — откроется окно TINY BROWSER (повторное нажатие обновляет
   страницу).
3. Нажмите **Ctrl+L**, введите адрес (например
   `http://info.cern.ch/hypertext/WWW/TheProject.html`), домен или запрос и
   нажмите **ENTER** или кнопку **GO**. Адресную строку можно редактировать:
   клик задаёт позицию каретки, ←/→ двигают её, Home/End — в начало/конец,
   Backspace/Delete удаляют символы.
4. Кликайте по синим подчёркнутым ссылкам; **BACK** возвращает назад,
   **HOME** — на стартовую страницу.
5. Прокрутка: стрелки **↑/↓**, **PageUp/PageDown** или колесо мыши; позицию
   показывает полоса справа от текста и счётчик `LINE x/y`.
6. **ESC** возвращает на стартовую страницу, **Ctrl+R** обновляет страницу.

На старте браузер показывает встроенную стартовую страницу с ссылками —
она работает даже без запущенного помощника.

## TINY SHELL — терминал, пакеты и git

Нажмите **F9** (или выберите TERMINAL в меню «Пуск»). Оболочка показывает
виртуальный корень `/`, который `nethelper.py` отображает в папку `tinyos_fs/`
рядом с проектом. Команды:

```
help                    список команд
pwd                     текущий каталог
ls [DIR]                содержимое каталога
cd DIR                  перейти в каталог (.. — наверх)
mkdir DIR               создать каталог
cat FILE                показать содержимое файла
git clone URL           клонировать репозиторий (http/https)
git status              состояние репозитория в текущем каталоге
git log                 последние коммиты
pip install NAME        установить пакет через pip в site-packages
pip install NAME==VER   установить конкретную версию
pip show NAME           данные о пакете с PyPI без установки
pip uninstall NAME      удалить пакет и его файлы
pip list                список установленных пакетов
apt update              обновить метаданные репозиториев (dnf makecache)
apt search TEXT         найти системные пакеты
apt install NAME        скачать RPM, распаковать и установить
apt remove NAME         удалить файлы пакета
apt list                список установленных системных пакетов
apt show NAME           информация о пакете из репозитория
apt files NAME          файлы установленного пакета
apt upgrade             обновить установленные пакеты
apt clean               очистить кэш загрузок
pkg / dnf               алиасы apt
which CMD               путь установленной программы
clear / ver / date      очистить экран / версия / дата
echo TEXT               вывести текст
uptime / uname          время работы / данные системы
history                 история команд
beep                    писк через PC speaker
play 0|1|2              мелодия через PC speaker
stop                    остановить звук
ps                      список задач ядра
kill N / resume N       остановить / возобновить задачу
top                     диспетчер задач
snake                   запустить игру
dmesg                   журнал ядра
free                    память по CMOS
df [DIR] / du [DIR]     использование файловой системы
tree [DIR]              дерево каталогов
head FILE / tail FILE   первые / последние строки
wc FILE                 строки, слова, байты
edit FILE               открыть файл в редакторе
calc                    открыть калькулятор
panic                   показать экран KERNEL PANIC
```

**↑ / ↓** в терминале перебирают историю команд, **PageUp/PageDown**
прокручивают вывод, ←/→ двигают каретку, Backspace/Delete удаляют символы.

`pip install` действительно запускает `python3 -m pip install --target` на
хосте: файлы пакета появляются в `tinyos_fs/site-packages`, а версия и
описание сохраняются в `installed_packages.json`. `git clone` выполняет
настоящий `git clone --depth 1`.

`apt install NAME` — это системный менеджер пакетов, как в Linux. Хост
скачивает RPM вместе с зависимостями (`dnf download --resolve`), каждый
пакет распаковывается в `tinyos_fs` через `rpm2cpio | cpio`, а реестр
`apt_installed.json` хранит версию, размер, архитектуру и список файлов.
После установки программу можно запустить просто по имени, например:

```
apt install cowsay
cowsay HELLO FROM TINY OS
```

Запуск идёт в `bwrap`: корень хоста только для чтения, `/usr` собран из
хостового `/usr` и `tinyos_fs/usr`, сеть и PID изолированы. Поэтому
работают figlet, cowsay, fortune и другие консольные программы, но не
интерактивные TUI. `apt remove NAME` удаляет файлы пакета, не задевая
общие файлы других пакетов.

Базовая ОС сама по себе не исполняет Python и не является Linux: команды
выполняет хост-помощник через COM1. Без запуска через `./run.sh` терминал
сообщит `OFFLINE`.

## Сборка

Нужны `gcc`, `ld`, `as`, `objcopy`, `python3`, `dd`:

```bash
./build.sh
```

Результат — `os.img` (загрузочный образ диска) и `tinyos.iso` (загрузочный ISO).

## Запуск

С реальным интернетом:

```bash
./run.sh
```

без браузера:

```bash
qemu-system-i386 -drive format=raw,file=os.img -m 64 -k en-us
```

с ISO:

```bash
qemu-system-i386 -cdrom tinyos.iso -boot d -m 64 -k en-us
```

## Структура

|------|------------|
| `boot.S` | загрузчик + GDT + protected mode, загрузка больших ядер и очистка BSS |

| `kernel.c` | ядро: графика, ввод, окна, HTML-рендерер, COM1 |
| `kernel.ld` | скрипт линковки ядра (0x10000) |
| `tools/genfont.py` | генератор шрифта 5×7 (83 глифа) |
| `nethelper.py` | хост-помощник: HTTP/HTTPS, pip/pkg, git и ФС |
| `run.sh` | запуск QEMU + помощника |
| `build.sh` | сборка образов |
| `os.img` | готовый загрузочный образ (67 072 байт) |
| `tinyos.iso` | готовый загрузочный ISO (El Torito, no emulation) |
| `tinyos_fs/` | виртуальная ФС терминала (создаётся помощником) |
| `installed_packages.json` | реестр Python-пакетов (создаётся помощником) |
| `apt_installed.json` | реестр системных пакетов (создаётся помощником) |
| `pkg_cache/` | кэш скачанных RPM (создаётся помощником) |
| `GITHUB.md` | готовые тексты для GitHub (About, topics, commit, release) |
